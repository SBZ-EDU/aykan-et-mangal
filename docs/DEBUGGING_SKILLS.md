# ۴۳ مهارت دیباگ — کارنامه‌ی عملی پروژه‌ی آیکان (v7.13.1)

فهرست ۳۰ تکنیکی که در این پروژه آموخته/به‌کار گرفته شد؛ ستاره‌دارها = همین امروز نتیجه دادند.

## فایل و نسخه

1. ⭐ **راستی‌آزمایی نسخه‌ی فایل قبل از هر وصله** — فایل‌های لوکال بین نوبت‌ها به snapshot قدیمی برمی‌گردند؛ اول مارکر نسخه grep شود (امروز: index.html به pre-i18n برگشته بود و **دو دیپلوی قبلی ناخواسته سایت را به فارسیِ قدیمی برگردانده بودند** — با بازیابی از ریپو رفع شد)
2. **مقایسه‌ی md5/بایت لوکال ↔ ریپو ↔ زنده** قبل از فرض «زنده = لوکال»
3. ⭐ **تفکیج کاراکتر (Python len) از بایت (wc -c)** — عددهای UTF-8 چندبایتی گمراه‌کننده‌اند

## وصله‌ی ایمن

4. **grep بایت‌به‌بایت لنگر قبل از replace** — ترتیب attribute ها و نقل‌قول‌ها varies
5. **assert تعداد occurrence** قبل از هر جایگزینی (count==1)
6. **فهرست شکست‌ها (fails list)** در اسکریپت وصله — همه‌ی رپ‌ها گزارش شوند، نه silence
7. **node --check بعد از هر وصله** روی ورکر + استخراج و چک جداگانه‌ی هر `<script>` درون HTML
8. ⭐ **استخراج escape-آگاه template literal** — درون backtick ورکر، `\\/` باید eval شود (`\\(.)/g` → کاراکتر خام)؛ رشته‌ی خامِ کاراکتر‌به‌کاراکترِ فایل regex را می‌شکند و خطای «Invalid regular expression flags» می‌دهد
9. **fallback ریجکس برای concats سراسری** وقتی لنگر از مرز رشته‌ها می‌گذرد

## تست مرورگر

10. **mock سرور HTTP** برای UI وابسته به API (Node http + JSON ثابت)
11. ⭐ **پروب DOM برگرفی به‌جای body.innerText** — innerText متنِ `<script>` را هم برمی‌گرداند و «فارسی در ترکی» کاذب می‌سازد
12. ⭐ **مسدودسازی فراخوانی‌های بیرونی** (pg.route → abort برای ipapi.co) تا تست قطعی شود
13. **ضمیمه‌شدن به pageerror + console.error** و تفکیک خطای واقعی از 404 فاوآیکون
14. **اسکن سرریز ۳۹۰px** با scrollWidth + ممیزی getBoundingClientRect برای یافتن مقصر (جدول بدون min-width)
15. **تست در دسکتاپ + موبایل** بعد از هر تغییر CSS

## دیباگ دیتا و API

16. ⭐ **ممیزی آلودگی متقاطع زبان‌ها** — اسکن حروف فارسی/عربی در tr/en/de/ru و سیریلیک در غیر ru (اسکریپتی، کل دیکشنری)
17. ⭐ **ممیزی پوشش کلیدها**: همه‌ی کلیدهای استفاده‌شده در کد باید در دیکشنری باشند — `tx(lang,"fallback")` بدون کلید = پیام خالیِ بی‌صدا
18. ⭐ **فرمت واقعی داده را از منبع بگیر نه حدس**: دسته‌های trend با ایموجی ذخیره می‌شوند («💰 قیمت گوشت») — ماکِ بدون ایموجی = fallback فارسیِ کاذب
19. **شبیه‌ساز بات بدون توکن** — /api/sim با x-sim-key کل جریان ربات را تست می‌کند
20. ⭐ **نگاشت دقیق خطا**: 401=توکن باطل / getChat ناموفق=ربات ادمین کانال نیست — پیام قابل‌عمل بساز
21. **مقایسه‌ی شمارش‌ها بین محیط‌ها** (orders/leads/ai در دو اکانت) برای تشخیص ناهمگامی
22. **export/import با dedup** برای همگام‌سازی D1 (seen-set + ON CONFLICT DO NOTHING)
23. ⭐ **ممیزی گیت‌های auth در روتر** — endpoint جدید باید هم در هندلر و هم در فهرست مسیرهای روتر باشد (404 = جاافتاده در روتر)
24. ⭐ **ممیزی امنیتی endpoints موجود** — /api/b2b قبل از گیت auth بود؛ هر مسیر حساس پشت Bearer برود

## زیرساخت

## مهارت‌های ۳۱–۳۸ (v7.12.0 — ردیابی «فارسی در ترکی»)

31. ⭐ **پیمایشگر TextNode به‌جای اسکن عنصر** — اسکنِ «عناصر برگ» والدهای دارای متن+فرزند (mixed-content) را از قلم می‌اندازد؛ با `document.createTreeWalker(body, SHOW_TEXT)` همه‌ی متن‌های قابل‌ دیدن بررسی می‌شوند — این کورگاه باعث شد دو دور «تست سبز» ببینیم در حالی که باگ واقعی بود
32. ⭐ **ممیزی mixed-content برای i18n:** عنصری که متن ایستا + فرزندِ data-i18n دارد در هر زبانی جز زبانِ متن ایستا «مخلوط» رندر می‌شود — الگو: «ما گوشت نمی‌فروشیم؛ [ترکی] را می‌فروشیم»
33. **الگوی data-i18n-html:** برای بلوک‌های ترجمه با مارک‌آپ داخلی (em/b/small)، کل innerHTML از دیکشنری عوض می‌شود؛ مقدار FA از بازسازی محتوای اصلی ساخته می‌شود
34. **حفظ شناسه‌های داینامیک:** عنصر دارای `id` که JS آپدیتش می‌کند (rf-kg/rf-est) نباید innerHTML بگیرد — با زیر-اسپن‌های جدا و کلیدهای مخصوصِ برچسب/واحد بازسازی شود
35. ⭐ **ممیزی همه‌ی آرایه‌های داده × همه‌ی زبان‌ها:** هر آرایه‌ی چندزبانه (UNITS، آیتم‌های RFQ، ITEMS) باید برای هر زبان کلید داشته باشد؛ fallback زبانِ اول = نشت آن زبان به بقیه («650 ₺ / کیلو» در آلمانی)
36. **استثنای جد در ممیزی ایستا:** فرزندانِ داخل مقدارِ data-i18n-html در HTML ایستا فارسی‌اند اما بی‌خطرند — ممزی باید `find_parent(attrs={'data-i18n-html'})` را حذف کند تا مثبت کاذب ندهد
37. **اسکریپت وصله‌ی idempotent:** بعد از شکست وسط اجرا (دیکشنری نوشته شد، عناصر نه) اجرای مجدد نباید دوبار درج کند — check-before-insert
38. ⭐ **کش edge بعد از دیپلوی:** پاسخ اول می‌تواند نسخه‌ی کش‌شده‌ی قدیمی باشد (cf-cache-status: HIT) — تست زنده با پارامتر cache-buster یا تکرار بعد از چند دقیقه؛ و راستی‌آزمایی حجم/مارکر فایل زنده با curl

## مهارت‌های ۳۹–۴۳ (v7.13.1 — دور دیباگ کامل)

39. ⭐ **کش per-isolate برای state حساس ممنوع:** کش ۳۰ثانیه‌ای تنظیمات روی هر isolate جدا живد → نوشتن روی A تا ۳۰ ثانیه روی B دیده نمی‌شود؛ نشانه‌ها: «دستور ادمین بعد از لاگین رد می‌شود» ولی چند دقیقه بعد کار می‌کند؛ راه‌حل: stateهای حساس (bot_state) همیشه fresh از D1
40. ⭐ **نوشتن state کهنه = از بین بردن داده:** read-modify-write روی isolate کهنه فیلدهای تازهٔ دیگر را خاموش می‌کند (مثال: /duyuru روی isolate کهنه admin_chat را از دیتابیس پاک می‌کرد) — همیشه قبل از write، fresh بخوان
41. **ممیزی زبانی جدا برای مسیر ادمین:** متن‌های customer چندزبانه اند ولی متن‌های ادمین غالباً فراموش می‌شوند — گیت ادمین (handleAdminCommand + callback های adm:/lb:) را جدا با حروف ترکی گشته شود
42. **تست دیالوگ در Playwright:** alert() خودکار dismiss می‌شود → اعتبارسنجی «بی‌پیام» به نظر می‌رسد؛ handler پیوست (pg.on("dialog")) + تصاویر lazy فقط بعد از اسکرول کامل چک شوند (complete/naturalWidth قبل از اسکرول = کاذب)
43. **regex گروه‌بندی هزارگان:** `\B(?=(\d{3})+(?!\d))` — علامت تعجب باید `\d` باشد نه `\.`؛ با ۱۴۷۲۰ تست کن نه فقط ۱۸۳۱ (۵ رقمی باگ `1.4.720` را می‌گیرد) و اعشار (۲.۵) نباید گروه بگیرد
