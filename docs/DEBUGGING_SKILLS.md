# ۳۰ مهارت دیباگ — کارنامه‌ی عملی پروژه‌ی آیکان (v7.11.0)

فهرست ۳۰ تکنیکی که در این پروژه آموخته/به‌کار گرفته شد؛ ستاره‌دارها = همین امروز نتیجه دادند.

## فایل و نسخه

1. ⭐ **راستی‌آزمایی نسخه‌ی فایل قبل از هر وصله** — فایل‌های لوکال بین نوبت‌ها به snapshot قدیمی برمی‌گردند؛ اول مارکر نسخه grep شود (امروز: index.html به pre-i18n برگشته بود و **دو دیپلوی قبلی ناخواسته سایت را به فارسیِ قدیمی برگردانده بودند** — با بازیابی از ریپو رفع شد)
2. **مقایسه‌ی md5/بایت لوکال ↔ ریپو ↔ زنده** قبل از فرض «زنده = لوکال»
3. ⭐ **تفکیج کاراکتر (Python len) از بایت (wc -c)** — عددهای UTF-8 چندبایتی گمراه‌کننده‌اند

## وصله‌ی ایمن

4. **grep بایت‌به‌بایت لنگر قبل از replace** — ترتیب attribute ها و نقل‌قول‌ها varies
5. **assert تعداد occurrence** قبل از هر جایگزینی (count==1)
6. **فهرست شکست‌ها (fails list)** در اسکریپت وصله — همه‌ی رپ‌ها گزارش شوند، نه silence
7. **node --check بعد از هر وصله** روی ورکر + استخراج و چک جداگانه‌ی هر `<script>` درون HTML
8. ⭐ **استخراج escape-آگاه template literal** — درون backtick ورکر، `\\/` باید eval شود (`\\(.)/g` → کاراکتر خام)؛ رشته‌ی خامِ کاراکتر‌به‌کاراکترِ فایل regex را می‌شکند و خطای «Invalid regular expression flags» می‌دهد
9. **fallback ریجکس برای concats سراسری** وقتی لنگر از مرز رشته‌ها می‌گذرد

## تست مرورگر

10. **mock سرور HTTP** برای UI وابسته به API (Node http + JSON ثابت)
11. ⭐ **پروب DOM برگرفی به‌جای body.innerText** — innerText متنِ `<script>` را هم برمی‌گرداند و «فارسی در ترکی» کاذب می‌سازد
12. ⭐ **مسدودسازی فراخوانی‌های بیرونی** (pg.route → abort برای ipapi.co) تا تست قطعی شود
13. **ضمیمه‌شدن به pageerror + console.error** و تفکیک خطای واقعی از 404 فاوآیکون
14. **اسکن سرریز ۳۹۰px** با scrollWidth + ممیزی getBoundingClientRect برای یافتن مقصر (جدول بدون min-width)
15. **تست در دسکتاپ + موبایل** بعد از هر تغییر CSS

## دیباگ دیتا و API

16. ⭐ **ممیزی آلودگی متقاطع زبان‌ها** — اسکن حروف فارسی/عربی در tr/en/de/ru و سیریلیک در غیر ru (اسکریپتی، کل دیکشنری)
17. ⭐ **ممیزی پوشش کلیدها**: همه‌ی کلیدهای استفاده‌شده در کد باید در دیکشنری باشند — `tx(lang,"fallback")` بدون کلید = پیام خالیِ بی‌صدا
18. ⭐ **فرمت واقعی داده را از منبع بگیر نه حدس**: دسته‌های trend با ایموجی ذخیره می‌شوند («💰 قیمت گوشت») — ماکِ بدون ایموجی = fallback فارسیِ کاذب
19. **شبیه‌ساز بات بدون توکن** — /api/sim با x-sim-key کل جریان ربات را تست می‌کند
20. ⭐ **نگاشت دقیق خطا**: 401=توکن باطل / getChat ناموفق=ربات ادمین کانال نیست — پیام قابل‌عمل بساز
21. **مقایسه‌ی شمارش‌ها بین محیط‌ها** (orders/leads/ai در دو اکانت) برای تشخیص ناهمگامی
22. **export/import با dedup** برای همگام‌سازی D1 (seen-set + ON CONFLICT DO NOTHING)
23. ⭐ **ممیزی گیت‌های auth در روتر** — endpoint جدید باید هم در هندلر و هم در فهرست مسیرهای روتر باشد (404 = جاافتاده در روتر)
24. ⭐ **ممیزی امنیتی endpoints موجود** — /api/b2b قبل از گیت auth بود؛ هر مسیر حساس پشت Bearer برود

## زیرساخت

25. **CLOUDFLARE_ACCOUNT_ID برای توکن‌های scoped** — بدون آن wrangler به /memberships می‌رود و 9106 می‌دهد
26. **UA تنظیم‌شده در curl به ورکرها** — UA پایتون = 403
27. **دستور wrangler از node_modules محلی** (/tmp/wr) — نصب global مجاز نیست
28. **ری‌استارت سرور ماک بعد از هر ویرایش کد** — کد قدیمی در حافظه می‌ماند

## فرایند

29. ⭐ **دیباگ بعد از هر دیپلوی روی زنده** — تست لوکال کافی نیست؛ ۱۲/۱۲ زنده + صفر خطای JS
30. **چرخه‌ی: ممیزی → وصله → تست → دیپلوی → تست زنده → کامیت/ریلیز** برای هر تغییر، با CHANGELOG فارسی

## باگ‌های واقعی که همین چک‌لیست امروز گرفت

1. برگشت سایت به نسخه‌ی فارسی قدیمی (دیپلوی پوشه‌ی snapshot-شده) — ریشه‌ی «فارسی در ترکی» که کاربر دید
2. پیام خالی ربات برای متن نامفهوم (کلید fallback/unknown)
3. /api/b2b بدون احراز هویت
4. مسیر /api/sync در روتر ثبت نشده بود (404)
5. ⛔ دوبله در پیام خطای تست تلگرام
6. جدول‌های پنل در موبایل سرریز (v7.9) و کاما به‌جای نقطه‌ی ترکسی (v7.9)
