# ۳۰ مهارت ساخت آیکون — کارنامه‌ی عملی پروژه‌ی آیکان (v7.16.0)

> هر مهارت از یک تصمیم/رویداد واقعی این پروژه آموخته شده است.

## بنیادها

1. **ایموجی فونت سیستم است، نه دارایی** — 🥩 در ویندوز/مک/اندروید متفاوت رندر می‌شود؛ هرگز به پیکسل‌ دقیق آن متکی نشو، به «معنا» متکی شو
2. **یک ایموجی، یک مفهوم، همه‌جا** — نقشه‌ی ثابت: 💰 قیمت · 🥩 گوشت · 🔥 منقل · 🧾 سفارش · 📢 اعلان؛ وقتی کاربر 💰 را دید یعنی قیمت، بدون ترجمه
3. **ایموجی + متن، نه ایموجی تنها** — دکمهٔ «💬 Sipariş» همیشه با کلمه است؛ اگر فونت ایموجی نبود، متن می‌ماند و دکمه بی‌نام نمی‌شود
4. **ترتیب استاندارد: آیکون اول، فاصله، بعد متن** — در RTL هم همین ترتیب منطقی می‌ماند چون ایموجی جهت‌خنثی است
5. **آیکون تزئینی → aria-hidden؛ آیکون کاربردی → aria-label** — ایموجیِ داخل دکمه‌ی متنی تزئینی است؛ دکمه‌ی فقط-آیکون باید aria-label داشته باشد

## دسترس‌پذیری

6. ⭐ **دکمه‌ی فقط-آیکون بدون aria-label ممنوع** — 🇹🇷 یا ☰ برای صفحه‌خوان «دکمه» خوانده می‌شود و بس
7. ⭐ **aria-label باید به زبانِ فعال باشد** — «واتس‌اپ» روی صفحه‌ی آلمانی غلط است؛ در applyLang با نقشهٔ AY_ARIA به‌ازای هر زبان آپدیت شود
8. **aria-expanded برای دکمه‌های دوحالته** — همبرگر ☰/✕ هنگام باز/بسته true/false می‌دهد
9. **نام زبان = بهترین aria برای دکمه‌ی زبان** — aria-label="Deutsch" بهتر از 🇩🇪 برای صفحه‌خوان
10. **alt معنادار برای عکس‌های آیکون‌گونه** — «Aykan Şube 1 — Bağcılar Göztepe» نه «resim»

## زبان و پرچم

11. ⭐ **پرچم ≠ زبان** — 🇮🇷 فارسیِ ایران است ولی فارسی فقط مال ایران نیست؛ وقتی سیاست «فارسی فقط برای ادمین» آمد، دکمه‌ی 🇮🇷 از سایت حذف شد و ۵ زبان عمومی ماند
12. **حذف دکمه کافی نیست — مسیرهای ورود را هم ببند** — saved-lang=«fa» → fallback به tr؛ تشخیص IP ایران → tr؛ وگرنه کاربر قدیمی همچنان فارسی می‌ماند
13. **پرچم در ویندوز فقط کد دوحرفی است (FL=FL)** — Segoe UI Emoji پرچم‌ها را روی ویندوز نشان نمی‌دهد؛ aria-label نام زبان جانشین دیداری است
14. **تولتیپ چندزبانه برای سوییچر زبان** — "Dil / Sprache / Русский / Language / اللغة" یک خط، بدون دیکشنری

## فاوآیکون و پلتفرم

15. ⭐ **favicon با SVG دیتا-URI و ایموجی — بدون فایل** — `<link rel=icon type=image/svg+xml href="data:image/svg+xml,…%F0%9F%A5%A9…">`؛ عکس JPEG 420px جای فاوآیکون، تار و سنگین بود
16. **درصد-انکود ایموجی در data-URI** — 🥩 = %F0%9F%A5%A9 (UTF-8)؛ آپاستروف‌ها هم باید کد شوند وگرنه لینک می‌شکند
17. **theme-color همرنگ پس‌زمینه** — متای #0f0c0b نوار مرورگر موبایل را با تم تیره یکدست می‌کند
18. **og:title بدون اتکا به ایموجی** — برخی پلتفرم‌ها ایموجی متا را حذف می‌کنند؛ متن باید خودکفا باشد

## RTL و جهت

19. ⭐ **آیکون‌های جهت‌دار را در RTL آینه کن** — ▲/☰ جهت‌خنثی‌اند؛ ↩/◀ باید mirror شوند (transform: scaleX(-1) یا کاراکتر معادل)
20. **inset-inline-end به‌جای right/left** — دکمه‌ی همبرگر با CSS منطقی خودکار در فارسی/عربی سمت چپ می‌نشیند
21. **پین نقشه استاندارد سرویس را استفاده کن** — pm2rdm/pm2blm یاندکس = پین قرمز/آبی؛ کاربر رنگ‌ها را از هزار بار دیدن می‌شناسد

## وضوح و کنتراست

22. ⭐ **آیکون روی تم تیره باید وزن بصری بگیرد** — ایموجی رنگی روی #0f0c0b خوب می‌نشیند ولی آیکون تک‌رنگ SVG باید رنگ روشن بگیرد (currentColor)
23. **SVG با currentColor وارث متن می‌شود** — یک آیکون، هر رنگی که والد بگیرد؛ برای تم روشن/تیره بدون کپی
24. **کنتراست آیکون‌دار را با متنش بسنج** — 🇹🇷 داخل دکمه‌ی ۲۹px خاکستری‌شده (filter: grayscale(.75)) — حالت فعال filter:none برمی‌گرداند
25. **آیکون در متن متحرک ساده باشد** — تیکر فقط ایموجی‌های شناخته‌شده (🥩⚖️🚚📲🕌❄️🔥)؛ آیکون پیچیده در حرکت ناخوانا است

## اندازه و لمس

26. **هدف لمسی ۴۴×۴۴ (WCAG)** — همبرگر 44px؛ دکمه‌های زبان ۲۹px متراکم‌اند ولی کنار هم ناحیهٔ کلیک پیوسته می‌سازند
27. **آیکون هدر با logotype یکجا** — بلوگوی ۴۶px قرمز + نام + شعار؛ در موبایل لوگو ۴۰px و شعار مخفی — سلسله‌مراتب کوچک‌شدن از قبل طراحی شود
28. **☰ کاراکتر تایپوگرافیک است نه ایموجی** — یکدستی رندر و عرض ثابت؛ ✕ بسته‌شدن هم همین‌طور

## ثبات و تست

29. ⭐ **فرهنگ آیکون مکتوب شود** — همین سند + کلیدهای I18N که ایموجی را داخل مقدار دارند (s192="💬") = منبع واحد؛ آیکون جدید فقط از نقشه
30. **آیکون‌ها را در دو موتور تست کن** — کروم و فایرفاکس فونت ایموجی متفاوت دارند؛ سوئیت Playwright در هر دو اجرا شود (پروژه: ۳۱/۳۱ + ۱۱/۱۱ زنده)
