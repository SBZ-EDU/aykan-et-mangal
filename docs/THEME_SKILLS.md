# ۳۰ مهارت یافتن تم یک سایت — کارنامه‌ی عملی پروژه‌ی آیکان (v7.18.0)

> هر مهارت از یک تصمیم/رویداد واقعی این پروژه آموخته شده است — استخراج تم coskunet.com.tr (Coşkun Et) و اعمال آن روی سایت آیکان.

## بنیادها — شناسایی

1. ⭐ **اول اثر انگشت پلتفرم/تم را از سورس بخوان** — `Shopify.theme = {"schema_name":"Horizon","schema_version":"4.1.5","theme_store_id":2481}`؛ وردپرس: مسیر `/wp-content/themes/<name>`؛ دانستن تمِ زیرین = نقشه‌ی راه ساختار توکن‌ها
2. **theme_store_id را در فروشگاه تم‌ها بگرد** — شناسه‌ی ۲۴۸۱ = مستندات رسمی Horizon؛ فهرست تنظیمات و فلسفه‌ی طراحی از همان‌جا
3. **ابزار خواندن صفحه فقط «محتوا» می‌دهد نه «ظاهر»** — برای تم باید HTML خام + فایل‌های CSS + مرورگر بی‌سر را بگیری؛ متنِ تبدیل‌شده به markdown رنگ و فونت ندارد
4. **پارامترهای ردیابی را از URL مرجع پاک کن** — `?srsltid=…` نتیجه‌ی شخصی‌سازی جستجو است؛ تم سایت با و بدون آن یکی است ولی کش را کثیف می‌کند
5. **HTML خام را با UA واقعی ذخیره کن** — `curl -A "Mozilla/5.0…"`؛ ۷۹۸KB سورس شامل تنظیمات تزریق‌شده‌ی تم است که در رندر دیده نمی‌شود ولی همه‌چیز آنجاست

## استخراج توکن‌های رنگ

6. ⭐ **مقادیر تنظیمات تم در HTML تزریق می‌شوند، نه در فایل CSS** — Shopify متغیرها را در `<style>` داخل صفحه می‌گذارد؛ `grep --color-background` روی HTML خام، نه فقط styles.css
7. **تکرار رنگ را بشمار، نه فقط فهرست کن** — `sort | uniq -c | sort -rn`: `#df231d` با ۱۷ تکرار = رنگ برندِ واقعی؛ یک رنگِ یک‌بارمصرف (sage) = رنگ تأکیدی
8. **CSS کامپایل‌شده‌ی پلتفرم «ساختار» است، «مقدار» نیست** — styles.css فقط نام متغیرها را تعریف می‌کند؛ مقدارها از تنظیمات فروشنده می‌آیند
9. **رنگ‌ها را در هر دو قالب بردار** — computed-style عدد rgb می‌دهد، سورس hex؛ جدول تبدیل داشته باش (`rgb(223,35,29)` = `#df231d`)
10. **پالت کامل، نه فقط رنگ اصلی** — برند `#df231d` + آجری عمیق `#7d2728` (تیترها/قیمت‌ها) + جوهر `#1B1C20` + زرد اعلان `#F5A800` + سِیج `#eef1ea` + سفید؛ هرکدام نقش دارد

## مرورگر بی‌سر — حقیقتِ رندر

11. ⭐ **getComputedStyle روی المان زنده = حقیقت نهایی** — کَسکید حل‌شده؛ هر ادعای سورس را با رندر راستی‌آزمایی کن
12. **پروبِ المان‌های امضادار** — نوار اعلان، هدر، h2، دکمه‌ی CTA، کارت محصول، قیمت، بج، تیکر، فوتر؛ برای هرکدام backgroundColor/color/font/radius/transform بردار
13. **borderRadius دکمه = امضای تم** — Horizon: گوشه‌تیزِ ۰ روی همه‌چیز به‌جز دکمه‌ی «Ekle» که pill (50px) است؛ این دوقطبی را حفظ کن
14. **الگوی تایپوگرافی را از وزن+تبدیل بخوان** — منو: uppercase وزن ۵۰۰ · CTA: uppercase · بدنه: 400 · تیتر سکشن: 500–700؛ فونت یکی است (Inter)، تفاوت با وزن و تبدیل ساخته می‌شود
15. **padding دکمه و ارتفاع نوارها = مقیاس واقعی** — CTA با 16×32 و نوار اعلان ۴۳px؛ این اعداد را عیناً منتقل کن نه حدس
16. **رنگ سکشن‌ها به‌ترتیب اسکرول = ریتم صفحه** — زرد → قرمز → سفید؛ color-blocking تمام‌عرض امضای Horizon است

## تحلیل تصویر

17. ⭐ **رنگ غالب بنر/لوگو را با PIL حساب کن** — دانلود → resize کوچک → getcolors → sort؛ بنر «Kırmızı Paket» واقعاً `#c41e1e` است، حدس نزن
18. **بنرهای hero متنِ پخته دارند** — رنگ و حال‌وهوای هیرو در خود تصویر است؛ پالت متن هیرو را از تصویر استخراج کن
19. **ابعاد دارایی نیت طراحی را لو می‌دهد** — بنر ۳۸۴۰px = full-bleed؛ ارتفاع اسلایدر ۵۶۳px از DOM — مقصد را با همین مقیاس بساز

## فونت‌ها

20. ⭐ **فونت را از computed بگیر + وزن‌های استفاده‌شده را جدا کن** — لینک گوگل‌فونت همه‌ی وزن‌ها را می‌آورد ولی تم فقط 400/500/700 مصرف می‌کند؛ فقط همان‌ها را لود کن
21. **فونت‌پیکِ تک‌فونتی** — Inter هم بدنه هم تیتر؛ سلسله‌مراتب با وزن/اندازه/تبدیل ساخته می‌شود نه تعویض فونت
22. **فونت مرجع ممکن است زبان مقصد را نداشته باشد** — Inter عربی ندارد → fallback از قبل بچین (Vazirmatn) و تست RTL انجام بده

## اعمال روی سایت مقصد

23. ⭐ **متغیرهای سایت مقصد را بازنگاشت کن، نه رنگ هاردکد پراکنده** — `--ink/--bg/--card/--red` را با توکن‌های مرجع پر کن؛ ۹۰٪ سایت با همین فلیپ می‌شود
24. **لایه‌ی تم جدید را در انتهای کَسکید بگذار** — درست قبل از `</style>`؛ برتری قطعی بدون جنگ specificity
25. **فلیپ تیره→روشن با متغیرها تمام نمی‌شود** — گرادیان‌ها، بوردرهای `rgba(255,255,255,…)` و سایه‌های هاردکد را جداگانه جارو کن وگرنه سفید روی سفید می‌ماند
26. **عناصر امضای مقصد را قربانی نکن** — تیکر قرمزِ آیکان ↔ marquee قرمزِ Coşkun هم‌خانواده‌اند؛ رنگش را به `#df231d` به‌روز کن ولی خودش را حذف نکن

## تست و تحویل

27. ⭐ **بعد از فلیپ تم، کنتراست همه‌ی سکشن‌ها را ماشینی بسنج** — متنِ روشن روی پس‌زمینه‌ی روشن، باگِ خاموشِ کلاسیکِ تغییر تم است؛ اسکریپت luminance/سطح رنگ بنویس
28. **جاروی کامل قبل از دیپلوی** — ۴-۵ عرض (۳۲۰-۱۴۴۰) + تعویض هر ۵ زبان + RTL عربی + فایرفاکس؛ تم جدید نباید ریسپانسیو را بشکند
29. **اسکرین‌شات نهایی از «زنده» بگیر نه لوکال** — کش edge و انتشار تدریجی دارایی‌ها فقط در production دیده می‌شود؛ اول ۴۰۴های دارایی را صبرکن و رفع کن
30. **تم بدون نسخه، تم نیست** — theme-color متا + /health ورکر + CHANGELOG + تگ/ریلیز گیت؛ هر تغییر تم یک نسخه‌ی کامل است (v7.18.0)
